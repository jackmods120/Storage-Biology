# Storage server (Vercel Blob + Firebase + Telegram)

Env variables (Vercel > Settings > Environment Variables):
- FIREBASE_API_KEY = FB_KEY from MainActivity.java
- ADMIN_EMAIL = ADMIN_EMAIL from MainActivity.java
- TELEGRAM_BOT_TOKEN, TELEGRAM_CHANNEL_ID (optional)
- BLOB_READ_WRITE_TOKEN (added automatically when you connect a Blob store: Vercel > Storage > Create > Blob)
